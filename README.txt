SpaceSEO Studio Refresh
- index.html is a self-contained responsive web app.
- Features: SEO title ideas, hook, description, hashtags, tags; topic ideas; saved packages; manual view tracker; JSON backup/restore.
- Run by opening index.html in a modern browser.
- For a permanent HTTPS link, upload index.html to the root of a GitHub repository and enable GitHub Pages for branch main, folder /(root).
- This is an independent helper, not a copy of YouSEO. It does not provide live search volume, competitor data, or official YouTube analytics.
- Saved data is stored in local browser storage. Export a backup before clearing browser data.
